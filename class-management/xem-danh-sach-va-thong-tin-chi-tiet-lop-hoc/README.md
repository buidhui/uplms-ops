# Danh sách lớp học

## I. Thông tin chung

{% hint style="info" %}
#### Phạm vi & Module liên quan

* **Module chính:** Class List / Class Detail
* **Module liên quan:** Course, Student, Mentor, Test/ Quiz, Resources
{% endhint %}

{% hint style="warning" %}
#### Điều kiện tiên quyết

* Tài khoản có quyền xem danh sách lớp học.
* Tài khoản có quyền xem thông tin chi tiết lớp học.
{% endhint %}

## IV. Các lỗi thường gặp & Hướng dẫn xử lý

| Lỗi / Tình huống                        | Nguyên nhân                                   | Cách xử lý                                    |
| --------------------------------------- | --------------------------------------------- | --------------------------------------------- |
| Không truy cập được màn hình Class List | Tài khoản chưa có quyền xem danh sách lớp học | Liên hệ Admin hệ thống để kiểm tra phân quyền |
| Không mở được màn hình Class Detail     | Tài khoản chưa có quyền xem chi tiết lớp học  | Liên hệ Admin hệ thống để kiểm tra phân quyền |
